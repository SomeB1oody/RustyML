# 2. 经典机器学习

在 RustyML 里，凡是不属于神经网络的部分，都归入经典机器学习：线性模型、树、核方法、聚类和降维。这类算法训练快、对数据量要求低，产出的模型也看得懂、说得清。先从它们入手，只有当问题确实需要一个深层网络时，再转向[神经网络](../Chapter-03/3.0._神经网络.md)。本章的每个估计器（estimator）都位于 `rustyml::machine_learning` 之下，共享同一份简单约定：用一个会做校验、返回 `Result` 的 `new` 构造，用 `fit` 训练，用 `predict` 推理。降维变换器在此之上多出 `transform` 和 `fit_transform`。这套节奏学会一次，十三个模型全都通用。

动手之前，先过一遍[快速上手](../Chapter-01/1.0._快速上手.md)——尤其是[使用ndarray准备数据](../Chapter-01/1.3._使用ndarray准备数据.md)，因为每个模型吃进去的都是 `Array2<f64>` 特征矩阵；还有[错误处理](../Chapter-01/1.6._错误处理.md)，因为构造函数和 `fit`/`predict` 交还的都是 crate 自己的 `Result`。特征的编码与缩放属于[数据预处理](../Chapter-04/4.0._数据预处理.md)；而你用来评判这些模型的准确率、轮廓系数和 R² 分数，则属于[模型评估](../Chapter-05/5.0._模型评估.md)。

每个模型共有的骨架，本章其余部分不过是在此基础上做变化：

```rust
use rustyml::machine_learning::LinearRegression;
use ndarray::array;

fn main() {
    // construct -> fit -> predict，每个估计器都在重复这套节奏
    let mut model = LinearRegression::new(true, 0.01, 1000, 1e-6).unwrap();
    let x = array![[1.0, 2.0], [2.0, 3.0], [3.0, 4.0]];
    let y = array![6.0, 9.0, 12.0];
    model.fit(&x, &y).unwrap();

    let preds = model.predict(&array![[4.0, 5.0]]).unwrap();
    println!("prediction: {:?}", preds);
}
```

各节自成一体，需要哪个模型可以直接翻过去；但若按顺序读，会从最简单的估计器一路自然爬升到最复杂的那些。

监督学习从带标签的样本中预测目标。[线性回归](./2.1._线性回归.md)拟合连续目标，可选 L1/L2 正则化，求解器能在梯度下降和闭式解之间选择——想把 fit/predict 这套流程刻进脑子里，从它入手最合适。[逻辑回归](./2.2._逻辑回归.md)沿用同一套梯度机制来做二分类。[K近邻](./2.3._K近邻.md)干脆跳过训练，靠邻近度分类，距离度量和加权方式都可挑选。[决策树](./2.4._决策树.md)把特征空间切成一条条可读的 if/else 规则，支持 ID3、C4.5、CART 三种算法，并带剪枝。[支持向量机](./2.5._支持向量机.md)既有核化的 `SVC`（SMO 求解器）来拟合弯曲的边界，也有快速的 `LinearSVC` 应对宽而高维的数据。[线性判别分析](./2.6._线性判别分析.md)把每个类别建模为共享协方差的高斯分布，一步同时完成分类与降维。

聚类把无标签数据分组。[KMeans](./2.7._KMeans聚类.md)用 k-means++ 初始化，把点划入固定数量的簇——速度快，也是常见的默认选择。[DBSCAN](./2.8._DBSCAN.md)按密度找出任意形状的簇，把离群点标为噪声，事先无需告诉它簇的数量。[MeanShift](./2.9._MeanShift.md)同样会自行确定簇的数量，办法是沿密度曲面往上爬。三者的评分都用[聚类指标](../Chapter-05/5.3._聚类指标.md)。

降维在压缩特征的同时保住数据结构。[主成分分析](./2.10._主成分分析.md)是去相关和压缩的线性主力。[核主成分分析](./2.11._核主成分分析.md)借助 RBF、多项式等核，把它推广到非线性结构。[t-SNE](./2.12._t-SNE.md)只为可视化服务，把高维数据嵌入二维或三维；它学不出可复用的投影，因此只提供 `fit_transform`，没有面向新样本的 `transform`。

异常检测自成一类：[孤立森林](./2.13._孤立森林.md)通过随机切分来衡量每个点被孤立的难易程度，无需任何标签就能标出离群点。
