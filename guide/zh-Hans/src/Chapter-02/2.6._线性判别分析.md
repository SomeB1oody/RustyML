# 2.6. 线性判别分析

线性判别分析（LDA）一次拟合，身兼两职。它是一个生成式分类器——把每个类别建模成一个高斯分布，各类均值不同、协方差矩阵在所有类别间共享，再用贝叶斯规则挑出最可能的标签；它同时是一个有监督的降维器——把特征投影到最能分开各类别的方向上。RustyML 的 `LDA` 一次 `fit` 就同时交出这两样：分类器一侧是 `predict`（还有 `decision_function` 和 `predict_proba`），投影一侧是 `transform` / `fit_transform`。本页覆盖真正的 API、它背后的自研线性代数、你选它就要接受的那套高斯假设，以及协方差退化为奇异时到底会发生什么。

## 2.6.1. crate 实现了什么

所有东西都在 `rustyml::machine_learning::{LDA, Shrinkage, Solver}` 下（也通过 [prelude](../Chapter-01/1.5._Prelude与模块导入.md) 重新导出）。模型吃一个 `f64` 特征矩阵和 `i32` 标签——LDA 是分类器，标签是整数类别 id，而不是浮点数。你要打交道的接口如下：

| 方法 | 签名（简化） | 返回值 |
| --- | --- | --- |
| `LDA::new` | `new(n_components: usize)` | `Result<LDA, Error>` |
| `LDA::default` | `default()` | `LDA`（成分数自动确定） |
| `with_solver` | `with_solver(Solver)` | `LDA` |
| `with_shrinkage` | `with_shrinkage(Shrinkage)` | `Result<LDA, Error>` |
| `fit` | `fit(&x, &y)`，其中 `y: &Array1<i32>` | `Result<&mut LDA, Error>` |
| `predict` | `predict(&x)` | `Result<Array1<i32>, Error>` |
| `decision_function` | `decision_function(&x)` | `Result<Array2<f64>, Error>` |
| `predict_proba` | `predict_proba(&x)` | `Result<Array2<f64>, Error>` |
| `transform` | `transform(&x)` | `Result<Array2<f64>, Error>` |
| `fit_transform` | `fit_transform(&x, &y)` | `Result<Array2<f64>, Error>` |

crate 里没有 QDA（二次判别分析）——只有共享协方差、线性边界这一种。getter `get_classes`、`get_priors`、`get_means`、`get_projection` 在 `fit` 前返回 `None`、`fit` 后返回 `Some(&…)`，这也是判断一个模型是否已训练最干净的办法。

## 2.6.2. 第一个分类器

先从 2D 里三个彼此分得很开的簇入手。`LDA::default()` 会自动定下成分数，所以当你只想要标签时，根本不必操心投影。

```rust
use ndarray::array;
use rustyml::machine_learning::LDA;

fn main() {
    // 三个紧凑、彼此分得很开的簇，每簇 3 个样本
    let x = array![
        [1.0, 1.0], [1.5, 0.8], [0.8, 1.2],
        [5.0, 5.0], [5.2, 4.8], [4.8, 5.2],
        [9.0, 1.0], [9.2, 0.8], [8.8, 1.2],
    ];
    let y = array![0, 0, 0, 1, 1, 1, 2, 2, 2];

    let mut lda = LDA::default();
    lda.fit(&x, &y).unwrap();

    let preds = lda.predict(&x).unwrap();
    println!("predictions: {:?}", preds);

    // 每个类别的判别得分（n_samples, n_classes）与 softmax 后验概率
    let scores = lda.decision_function(&x).unwrap();
    let proba = lda.predict_proba(&x).unwrap();
    println!("scores shape:   {:?}", scores.shape());
    println!("proba shape:    {:?}", proba.shape());
    println!("class order:    {:?}", lda.get_classes().unwrap());
}
```

三个预测入口共用同一个内核。对一个样本 `x`，LDA 为每个类别算一个线性判别得分 `score_j(x) = x · (Σ⁻¹ μ_j) − 0.5 · μ_j · Σ⁻¹ μ_j + ln(prior_j)`，其中 `Σ` 是共享协方差，`μ_j` 是类别均值，`prior_j` 是该类别在训练集里的频率。`decision_function` 把这些原始得分以 `(n_samples, n_classes)` 矩阵返回；`predict` 是它逐行取 argmax 再映射回原始标签；`predict_proba` 是同一批得分逐行做数值稳定的 softmax，所以每一行都是一个合法的、和为 1 的分布。`decision_function` 和 `predict_proba` 的列顺序跟着 `get_classes()` 走，它按升序排序——别假设它跟标签在 `y` 里首次出现的顺序一致。

这里的先验就是纯粹的类别频率（`n_class / n_samples`），对这个类别均衡的数据集来说是 `1/3, 1/3, 1/3`。当训练类别不均衡时这一点很关键：`ln(prior_j)` 这一项会把边界推向更稀有的类别，一个贝叶斯分类器本该如此。如果你需要各类别先验相等，就把训练集配平——构造器上没有 `priors=` 这样的覆盖开关。

## 2.6.3. 有监督投影与 n_classes − 1 上限

投影这一侧才是 LDA 区别于 PCA 的地方。LDA 找的是让类间散度相对类内散度最大化的方向，而这种具备非零区分度的方向只有 `n_classes − 1` 个（类间散度矩阵的秩至多为 `n_classes − 1`）。crate 强制执行这条上限：可用成分数是 `min(n_classes − 1, n_features)`，在 fit 时定下来。`LDA::default()`（或 `n_components = None`）取这个上限；`LDA::new(k)` 精确请求 `k` 个，若 `k` 超过上限则在 `fit` 时报错。

所以画一张 2D 散点图，你至少需要三个类别——两个类别只给得出一根判别轴。`fit_transform` 一次调用完成训练加投影：

```rust
use ndarray::array;
use rustyml::machine_learning::{LDA, Shrinkage, Solver};

fn main() {
    let x = array![
        [1.0, 1.0], [1.5, 0.8], [0.8, 1.2],
        [5.0, 5.0], [5.2, 4.8], [4.8, 5.2],
        [9.0, 1.0], [9.2, 0.8], [8.8, 1.2],
    ];
    let y = array![0, 0, 0, 1, 1, 1, 2, 2, 2];

    // 3 个类别 -> 至多 2 根判别轴；直接投到 2D
    let mut lda = LDA::new(2)
        .unwrap()
        .with_solver(Solver::Eigen)
        .with_shrinkage(Shrinkage::Auto)
        .unwrap();

    let coords = lda.fit_transform(&x, &y).unwrap(); // (9, 2)
    println!("embedding shape: {:?}", coords.shape());
    for (row, &label) in coords.outer_iter().zip(y.iter()) {
        println!("class {label}: ({:.3}, {:.3})", row[0], row[1]);
    }

    // 投影矩阵把 n_features -> n_components；它的每一列都是单位向量
    let w = lda.get_projection().unwrap();
    println!("projection shape: {:?}", w.shape()); // [2, 2]
}
```

```text
embedding shape: [9, 2]
projection shape: [2, 2]
```

投影矩阵 `W` 的形状是 `(n_features, n_components)`；`transform` 无非就是 `x · W`。每一列都归一化到单位 L2 范数，各列按类别区分度排序（广义特征值最大的排在最前），所以第一个成分就是那根最具区分力的轴——如果你之后想从同一次拟合里做 1D 降维，这一点很有用。因为一根判别轴和它的反向对分类的效果完全一样，任何一列的符号都是任意的；把画出来的坐标轴方向当成没有意义，永远别从中读出方向性。

`transform` 和 `fit_transform` 是同一个降维步骤；`fit_transform(&x, &y)` 就是 `fit(&x, &y)` 后面接一个 `transform(&x)`，只是省掉了重复校验两遍。

## 2.6.4. 求解器与自研线性代数

`Solver` 决定分类器评分系数 `Σ⁻¹ μ_c` 里那个共享协方差怎么求逆。有个重要、又极易被漏掉的事实：求解器只影响 `predict` / `decision_function` / `predict_proba`。`transform` 投影跟求解器无关——它永远来自对类内协方差的对称特征分解——所以换求解器改变的是决策边界的数值，但绝不会动到你的 2D 嵌入。

| `Solver` | 怎么评分 | 什么时候选它 |
| --- | --- | --- |
| `SVD`（默认） | 对 `Σ` 做 SVD 伪逆，截断小奇异值 | 通用默认；对秩亏最鲁棒 |
| `Eigen` | 对称特征分解求逆，极小特征值归零 | 协方差良态时；与 `SVD` 相当 |
| `LSQR` | 迭代式 Paige–Saunders 最小二乘，不形成显式逆 | 维度极高、把逆矩阵实际算出来很浪费时 |

三者在分得开的数据上得到的标签完全一致；差别只在于它们如何应对病态的 `Σ`。`SVD` 和 `Eigen` 都构造一个伪逆，丢掉那些奇异值 / 特征值低于相对容差的方向，于是秩亏的协方差是优雅退化，而不是直接炸掉。`LSQR` 干脆绕开逆矩阵，迭代求解每个 `Σ · coef_c = μ_c` 方程组，这在 `n_features` 很大时是省内存的选择。

线性代数完全是自研的纯 Rust——RustyML 刻意不带 LAPACK 或 `nalgebra` 依赖（见[优先自研数值实现](../Chapter-06/6.0._数学工具.md)）。对称特征分解是 Householder 三对角化加隐式位移 QL 迭代（经典的 EISPACK `tred2`/`tql2` 组合）；SVD 是单边 Jacobi 方法，能把小奇异值算到很高的相对精度；`LSQR` 是带滚动 Givens 旋转的 Golub–Kahan 双对角化。在 LDA 产生的中小规模协方差矩阵上，这些算法确定到机器精度，这也是 LDA 不需要随机种子的原因。

## 2.6.5. 收缩与协方差正则化

每个特征只有很少几个样本时，原始样本协方差是个带噪的估计，求逆会把噪声放大。收缩（shrinkage）把 `Σ` 往一个缩放后的单位阵拉，用一点点偏差换来方差的大幅下降。`Shrinkage` 有两种形式：

- `Shrinkage::Auto`——Ledoit–Wolf 闭式最优强度，直接从数据算出来，没有调参旋钮。
- `Shrinkage::Manual(alpha)`——显式给一个 `alpha ∈ [0, 1]`，`0` 是不收缩，`1` 完全收缩到单位阵目标。`with_shrinkage` 会校验它，若 `alpha` 落在 `[0, 1]` 之外或非有限，就返回 `Error::InvalidParameter`——这正是它返回 `Result` 的原因。

有两个值得知道的细节。第一，不管你怎么选收缩，RustyML 总会给协方差加一条极小的固定对角脊（约为平均方差的 `1e-6` 倍），纯粹是为了让分解稳定；所以 `Shrinkage::Manual(0.0)` 和完全不收缩得到的结果一模一样。第二——这是和 scikit-learn 的一处实打实的分歧——这里的收缩和求解器是正交的。scikit-learn 在它的 `svd` 求解器下拒绝收缩；RustyML 则在任何求解器跑之前就把收缩施加到协方差上，所以 `Solver::SVD` 配 `Shrinkage::Auto` 完全合法，而且往往正是你想要的。只要你有共线特征或样本-特征比很吃紧，就把 `Shrinkage::Auto` 当默认选择。

## 2.6.6. 假设，以及假设失效时的症状

LDA 的最优性建立在两条假设上：每个类别是高斯的，且所有类别共享同一个协方差矩阵。共享协方差正是让决策边界成为线性的原因——二次项相互抵消了。假设成立时，LDA 极其省数据，因为它是把所有类别汇到一起估一个协方差，而不是每类估一个。

假设失效时，症状很具体。如果各类别的协方差确实不同（异方差——一个类别是紧致的一团，另一个是散开的一片云），真正的贝叶斯边界是二次的，而 LDA 被逼成线性的边界会在离散程度不同的区域里系统性地误分类：那个更宽的类别往往会“吞掉”边界附近的地盘。crate 里没有 QDA 可退守，所以对强异方差数据，就换一个非线性分类器——[决策树](./2.4._决策树.md)、[带 RBF 核的 SVM](./2.5._支持向量机.md)，或者 [KNN 分类器](./2.3._K近邻.md)。如果某个类别是多峰的或者明显非高斯，即便分类器还能勉强撑着，投影也可能分不开它；在信任这个降维之前，先看一眼 `transform` 的散点。

## 2.6.7. 奇异协方差与高维

大家最常问的边界问题：当特征共线，或者 `n_features > n_samples`、协方差因此奇异时，会怎样？RustyML **不会**抛一个专门的“奇异矩阵”错误。它对 `n_features` 和 `n_samples` 的关系压根没有设防——唯一的样本数检查是 `n_samples` 必须大于 `n_classes`，且每个类别至少要有两个样本。秩亏的协方差通过两条途径被吸收：常开的对角脊把它往可逆方向轻推，而 `SVD`/`Eigen` 伪逆（以及投影内部的白化步骤）会直接把特征值低于相对容差的方向归零，转而投影到协方差的非零子空间上，而不是去除以约等于 0 的数。

```rust
use ndarray::array;
use rustyml::machine_learning::LDA;

fn main() {
    // 第三列是前两列之和：特征矩阵秩亏，
    // 共享协方差因此奇异
    let x = array![
        [1.0, 2.0, 3.0],
        [1.5, 2.5, 4.0],
        [2.0, 3.0, 5.0],
        [6.0, 5.0, 11.0],
        [6.5, 4.5, 11.0],
        [7.0, 5.5, 12.5],
    ];
    let y = array![0, 0, 0, 1, 1, 1];

    // 没有奇异矩阵错误：对角脊 + 伪逆吸收了秩亏
    let mut lda = LDA::default();
    lda.fit(&x, &y).unwrap();

    let coords = lda.transform(&x).unwrap(); // (6, 1)：2 个类别 -> 1 个成分
    assert!(coords.iter().all(|v| v.is_finite()));
    println!("reduced to {:?}, all finite", coords.shape());
}
```

投影唯一还可能罢工的地方是 `Error::Computation("Discriminant direction norm too small for stable projection")`，只有当某根被选中的判别轴塌缩成一个近乎零的向量时才会抛出——这发生在你要求的成分数超过了数据在其退化子空间里能支撑的数量。这是一次硬性的数值失败，不是校验层面的疏漏，所以把它当成一个信号：减少 `n_components`，或者把正则化调得更狠。对 `n_features > n_samples` 或严重共线的数据，别只指望那条固定的 `1e-6` 对角脊；打开 `Shrinkage::Auto`，它对协方差的调理远好于那个最小稳定器，这决定了你得到的是一个能用的投影，还是一个被噪声方向主导的投影。

## 2.6.8. LDA、PCA 与逻辑回归的对比

有三个“邻居”值得直接拿来对比，因为在它们之间做选择往往才是真正的问题。

| | 有监督？ | 边界 / 轴 | 假设 | 成分上限 |
| --- | --- | --- | --- | --- |
| **LDA** | 是（用标签） | 类别分离度最大的方向 | 高斯类别，共享协方差 | `n_classes − 1` |
| [**PCA**](./2.10._主成分分析.md) | 否（忽略标签） | 总方差最大的方向 | 无（只用二阶矩） | `n_features` |
| [**逻辑回归**](./2.2._逻辑回归.md) | 是 | 只有线性决策边界 | 对类别形状无假设 | （不是降维器） |

PCA 最大化方差，从头到尾都不看 `y`，所以如果数据的离散主要落在那个*最不能*分开类别的方向上，它的头部成分也会心安理得地和这个方向对齐；LDA 直接最大化分离度，代价是被卡在 `n_classes − 1` 根轴上。想要一个有监督的低维视图，或者一个快速的生成式分类器、而且你的类别大致高斯时，选 LDA；想要无监督压缩，或者需要多于 `n_classes − 1` 个维度时，选 PCA。

和逻辑回归的分野在于生成式对判别式。LDA 建模类别条件密度再套贝叶斯规则；逻辑回归直接建模 `P(y | x)`，对每个类别的形状不作任何假设。当高斯 / 等协方差假设确实成立时，LDA 能用更少的样本收敛到一个好边界。假设不成立时，逻辑回归是更鲁棒的线性分类器，因为它压根就没对类别形状许下承诺。一个常见的做法是两个都留着，让留出集上的准确率——用[分类指标](../Chapter-05/5.2._分类指标.md)量出来——来拍板。

## 2.6.9. 错误、持久化与可复现性

错误面遵循 crate 全局的[错误处理](../Chapter-01/1.6._错误处理.md)约定。`LDA::new(0)` 是 `Error::InvalidParameter`（成分数必须为正）。越界的 `Shrinkage::Manual` 同样是 `InvalidParameter`，在构建时就抓住。结构性问题在 `fit` 时浮现：类别少于两个、`n_samples ≤ n_classes`、某个类别只有一个样本、`n_components` 过大，全都是 `Error::InvalidInput`；`x` 里出现非有限值是 `Error::NonFinite`；`x`/`y` 长度不一致是 `Error::DimensionMismatch`。到 predict 或 transform 时，特征数不对是 `Error::DimensionMismatch`，未拟合的模型是 `Error::NotFitted("LDA")`。

```rust
use ndarray::array;
use rustyml::error::Error;
use rustyml::machine_learning::{LDA, Shrinkage};

fn main() {
    // 手动收缩必须落在 [0, 1]；1.5 会在你构建模型时被拒
    match LDA::new(1).unwrap().with_shrinkage(Shrinkage::Manual(1.5)) {
        Err(Error::InvalidParameter { name, .. }) => println!("rejected parameter: {name}"),
        _ => unreachable!(),
    }

    // n_components 只有在类别数已知后才有界，所以一个过大的请求
    // 能通过构造器、却在 fit 时失败
    let x = array![
        [1.0, 1.0], [1.5, 0.8], [0.8, 1.2],
        [5.0, 5.0], [5.2, 4.8], [4.8, 5.2],
    ];
    let y = array![0, 0, 0, 1, 1, 1]; // 2 个类别 -> max_components = 1
    let mut lda = LDA::new(2).unwrap();
    match lda.fit(&x, &y) {
        Err(Error::InvalidInput(msg)) => println!("fit rejected: {msg}"),
        _ => unreachable!(),
    }
}
```

一个已拟合的 `LDA` 用 `save_to_path` / `load_from_path` 序列化，它们走 postcard 二进制（这里的 `.bin` 只是个文件名——不管扩展名叫什么，格式都是二进制）。这趟往返会还原类别、先验、均值、投影，以及缓存的评分系数，所以加载回来的模型不用重新拟合就能给出一模一样的预测和变换。格式细节见[深入模型持久化](../Chapter-07/7.2._深入模型持久化.md)。

```rust
use ndarray::array;
use rustyml::machine_learning::LDA;
use std::fs;

fn main() {
    let x = array![
        [1.0, 1.0], [1.5, 0.8], [0.8, 1.2],
        [5.0, 5.0], [5.2, 4.8], [4.8, 5.2],
        [9.0, 1.0], [9.2, 0.8], [8.8, 1.2],
    ];
    let y = array![0, 0, 0, 1, 1, 1, 2, 2, 2];

    let mut lda = LDA::new(2).unwrap();
    lda.fit(&x, &y).unwrap();
    let before = lda.predict(&x).unwrap();

    let path = "lda_model.bin";
    lda.save_to_path(path).unwrap();
    let loaded = LDA::load_from_path(path).unwrap();
    let after = loaded.predict(&x).unwrap();

    assert_eq!(before, after);
    fs::remove_file(path).unwrap();
    println!("round-trip predictions identical");
}
```

LDA 是完全确定的：它不抽任何随机数，同样的数据每次都产出同样的投影、系数和标签——没有种子要设（与[可复现性与随机种子](../Chapter-07/7.1._可复现性与随机种子.md)里那些随机模型形成对比）。唯一的运行间自由度是每根判别轴那个任意的符号，这是特征向量的数学性质，不是不确定性。拟合会在工作量越过 crate 标定的阈值后，把逐类别统计和最后的标签扫描并行化，但并行永远不改变结果——它只改变你多快拿到结果，那是[性能调优与并行](../Chapter-07/7.3._性能调优与并行.md)的话题。
