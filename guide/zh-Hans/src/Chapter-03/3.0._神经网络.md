# 3. 神经网络

RustyML 内置了一个用纯 Rust 编写的小型深度学习框架。框架里的每个张量都是 `Tensor`，也就是 `ndarray::ArrayD<f32>` 的别名。张量持有单精度值，并且是动态阶的。框架跑在 CPU 上，不保留 autograd 记录带。每一层都手写自己的前向和反向传播，并通过一个扁平视图把参数交给优化器。因此整个框架保持确定、易于调试。

层只负责计算，它什么都不记住。`forward` 和 `backward` 都接收 `&self` 和一个 `&mut Ctx`。这个上下文承载训练标志、本趟的缓存、参数梯度，以及一次训练传播会改动的不可训练状态。因此构建好的模型是 `Send` 和 `Sync` 的，多个线程可以对着 1 个模型同时做推理。有 3 点把这个框架和多数框架区分开来：严格的 `f32` 精度、输入形状只在构建时到达模型 1 次，以及每个构造函数都返回 `Result`。

crate 提供 2 种模型类型，两者驱动的是同一批层。[`Sequential`](./3.1._Sequential模型.md) 是一条链。链上的每一层只接收 1 个输入，而这个输入就是它前一层的输出。[`Graph`](./3.10._图模型与合并层.md) 是一张有向图，图里的一个节点，就是 1 个层在其他节点的输出上的 1 次调用。因此一个图模型可以持有多个入口、多个出口、一条残差连接，或者 1 个被多个节点共享的层。`GraphBuilder` 负责收集节点，它的 `build` 会拒绝一个跑不起来的拓扑。

在开始本章前，请先读[第 1 章](../Chapter-01/1.0._快速上手.md)。也请读一下[使用 ndarray 准备数据](../Chapter-01/1.3._使用ndarray准备数据.md)和[安装与 Feature 配置](../Chapter-01/1.2._安装与Feature配置.md)，因为 `neural_network` 这个 feature 控制着整个模块的编译。还要读[错误处理](../Chapter-01/1.6._错误处理.md)，因为层和损失函数的构造函数都返回 `Result`。一个链式模型端到端的骨架长这样：

```rust
use rustyml::neural_network::{
    Shape,
    layers::{Activation, Dense},
    losses::MeanSquaredError,
    optimizers::Adam,
    sequential::SequentialBuilder,
};
use ndarray::Array;

fn main() {
    let x = Array::ones((8, 4)).into_dyn(); // 8 个样本，4 个特征
    let y = Array::ones((8, 1)).into_dyn(); // 8 个样本，1 个目标值

    // 构建器负责收集层，`build` 把到达每一层的形状交给那一层。
    // 不自洽的层堆叠在这里就被拒绝，此时还没有任何数据流动。
    let mut model = SequentialBuilder::new()
        .add(Dense::new(16, Activation::ReLU).unwrap())
        .add(Dense::new(1, Activation::Linear).unwrap())
        .build(&Shape::known(x.shape()))
        .unwrap();
    model.compile(
        Adam::new(0.001, 0.9, 0.999, 1e-8, 0.0).unwrap(),
        MeanSquaredError::new(),
    );

    model.fit(&x, &y, 5).unwrap();
    let preds = model.predict(&x).unwrap();
    println!("prediction shape: {:?}", preds.shape());
}
```

图模型把同样的层按节点接线。`GraphBuilder::input` 声明一个入口，`add` 把 1 个层放进模型并调用它一次，`build` 点名各个出口。每次调用都接收喂给它的那些节点，所以一条残差连接就是这份名单里多写 1 个名字。`Graph::fit`、`Graph::predict` 和 `Graph::evaluate` 每个入口收 1 个张量，每个出口给 1 个张量：

```rust
use ndarray::Array;
use rustyml::prelude::*;

fn main() {
    let x = Array::ones((8, 4)).into_dyn();
    let y = Array::ones((8, 1)).into_dyn();

    let mut builder = GraphBuilder::new();
    let input = builder.input(Shape::known(&[8, 4]));
    let hidden = builder.add(Dense::new(4, Activation::ReLU).unwrap(), &[input]);

    // `Add` 读 2 个节点，于是这个块把自己的输入加到该层算出的结果上。
    let residual = builder.add(Add::new(), &[input, hidden]);
    let head = builder.add(Dense::new(1, Activation::Linear).unwrap(), &[residual]);
    let mut model = builder.build(&[head]).unwrap();

    model.compile(
        Adam::new(0.001, 0.9, 0.999, 1e-8, 0.0).unwrap(),
        MeanSquaredError::new(),
    );
    model.fit(&[&x], &[&y], 5).unwrap();

    let preds = model.predict(&[&x]).unwrap();
    println!("prediction shape: {:?}", preds[0].shape());
}
```

上面的 `Add` 属于 merge 家族，图模型需要它，而链式模型用不了它。这一家族有 7 个层：`Add`、`Subtract`、`Multiply`、`Average`、`Maximum`、`Minimum` 和 `Concatenate`。前 6 个逐元素地归约自己的输入，`Concatenate` 则把它们沿 1 根轴拼接起来。[3.10](./3.10._图模型与合并层.md) 讲全这 7 个层，以及每个层的形状规则。`Average` 是这个 crate 里唯一被 2 个类别同时使用的名字，所以 prelude 根部保留的是 `metrics::Average`，而这个 merge 层是 `prelude::neural_network::Average` 或者 `neural_network::layers::Average`。

[Sequential 模型](./3.1._Sequential模型.md)是把一堆层变成可训练网络的容器。`SequentialBuilder` 收集层，`build` 为它们分配数组。构建出来的模型持有训练循环、优化器和损失函数。它对外暴露 `compile`、`fit`、`train_batch`、`evaluate`、`predict`、`summary`、`input_shape`、`output_shape` 以及权重的保存和加载。批次打乱的种子（`set_seed`）和学习率的读写对（`learning_rate` 与 `set_learning_rate`）也归它管。就算一个模型只需要某一个具体的层，也请先读这一节。

[全连接层与激活函数](./3.2._全连接层与激活函数.md)讲的是全连接层，它是表格类模型的主力层，也是大多数网络的输出环节。这个层收缩秩为 2 或更高的输入的最后一根轴，所以 1 个 kernel 也能变换一条序列的每一个时间步。这一节还讲 `Activation` 枚举（`ReLU`、`Sigmoid`、`Tanh`、`Softmax { axis }`、`Linear`），它既能折叠进某一层，也能自成一层。请把这一节放在第二个读。后面的内容都默认：`Dense` 层只声明 `units`，它的输入宽度来自 build 交给它的形状。

[损失函数](./3.3._损失函数.md)是 `compile` 里“目标”的那一半。它涵盖回归用的均方误差和平均绝对误差，以及分类用的二分类、多分类和稀疏多分类交叉熵。请仔细读这一节。各个损失的平均约定是故意不一致的：有的按元素平均，有的按预测位置平均。在这 2 种约定之间切换，会重新缩放实际生效的学习率。`CategoricalCrossEntropy` 和 `SparseCategoricalCrossEntropy` 都带一个 `from_logits` 标志，它决定模型的输出层还要不要再接一个 `Softmax`。`BinaryCrossEntropy` 没有这个标志，它始终要求输入是 `(0, 1)` 区间内的概率。

[优化器](./3.4._优化器.md)是 `compile` 里“更新”的那一半。它涵盖带动量的 SGD、Adam、AdamW、RMSprop 和 AdaGrad。这一节也涵盖按全局范数裁剪梯度（`global_clipnorm`）、耦合与解耦的权重衰减，以及训练途中调整学习率。3.1 到 3.4 这几节合起来，就是一个完整、可训练的前馈网络。

剩下的几节添加的是各种专用层。它们都能插进同一个 `Sequential`，也都能插进一个 `Graph`。[卷积层](./3.5._卷积层.md)提供 1D/2D/3D 卷积、把卷积反着跑从而把张量放大的转置卷积，以及面向空间数据的 depthwise 和 separable 变体。这 10 种层都接收 `dilation_rate`，它不花任何代价就能扩大感受野，`Conv1D` 还接收 causal 填充，供不允许看到未来的模型使用。[池化层](./3.6._池化层.md)提供无参数的最大和平均下采样，以及它们的全局变体，并在最后讲把空间轴放大回去的 `UpSampling1D/2D/3D`。[循环层](./3.7._循环层.md)涵盖用于序列的 `SimpleRNN`、`LSTM` 和 `GRU`。`return_sequences` 和 `go_backwards` 两个开关让它们能够堆叠和反向运行。这一节在最后讲把词索引变成这些层所读向量的 `Embedding`。[正则化与归一化层](./3.8._正则化与归一化层.md)涵盖 dropout、高斯噪声，以及 batch、layer、group、instance、unit 归一化。其中 dropout 这一族还包含 spatial dropout，以及让一整根轴共享 1 次抽样的 `noise_shape`。这一节还讲在第一个权重之前调理输入的无参数层 `Rescaling`。

其中只有最后一类的行为依赖模式。这类层在 `fit` 和 `predict` 下表现不同，而模型通过它构建的上下文来选定模式。

[权重保存与加载](./3.9._权重保存与加载.md)讲的是持久化。`save_to_path` 和 `load_from_path` 只持久化权重，格式是 postcard 二进制。它们不持久化网络结构。请在代码里搭出一模一样的层堆叠，再把权重加载进去。等手里有了一个值得留存的模型，再读这一节。格式细节和版本兼容的注意事项，见[深入模型持久化](../Chapter-07/7.2._深入模型持久化.md)。

[图模型与合并层](./3.10._图模型与合并层.md)为本章收尾。它讲 `GraphBuilder`、拼装拓扑的那 5 个调用，以及 `build` 在任何数据流动之前给出的各种拒绝。它还讲那 7 个合并层，以及每个层各自套用的形状规则。链式结构表达不了的模型，就读这一节。
