# 简介

RustyML 是一个完全用 Rust 写成的机器学习与深度学习库——没有需要链接的外部库，没有夹在中间的 Python 解释器，也没有需要跨越、来回搬运数组的 FFI 边界。本指南是这个库的实战伴侣：从一个全新的 `cargo new` 出发，一路讲到训练神经网络、调整热点内核里并行与串行的切换阈值，以及推断序列化一个模型时究竟有哪些字节落到磁盘上。它对应 RustyML **0.13**；书中每个完整示例都在这个版本下、开启 `full` 和 `show_progress` feature 编译通过，所以你读到的就是编译器认可的。

## 本指南是什么

每一个函数签名、每一条 trait 约束、每一个枚举变体，[docs.rs 上的 API 文档](https://docs.rs/rustyml)才是唯一权威。本指南不重复它，而是解释签名没说出口的那些取舍。docs.rs 告诉你 `Adam::new` 有哪些参数；本指南告诉你该选哪个优化器、为什么单次调用的 `random_state` 会压过全局种子而不是反过来，以及把一份保存的网络加载进层形状已经对不上的模型时会发生什么。它的写法就像一位熟悉这套代码的老同事带你逐一走读：具体、在该有主张的地方直接给主张，也如实告诉你某个估计器会在哪些边角上咬你一口。

crate 里经典机器学习那一半的东西几乎都是这个套路——构造、`fit`、`predict`，就是你在 scikit-learn 里熟悉的先 `(&x, &y)` 再 `&x` 的节奏：

```rust
use rustyml::prelude::machine_learning::*;
use ndarray::array;

fn main() {
    // 一个极小的线性关系：y = 3 * x
    let x = array![[1.0], [2.0], [3.0], [4.0]];
    let y = array![3.0, 6.0, 9.0, 12.0];

    // 参数依次为 (fit_intercept, learning_rate, max_iter, tolerance)
    let mut model = LinearRegression::new(true);
    model.fit(&x, &y).unwrap();

    let predictions = model.predict(&x).unwrap();
    println!("predictions: {:?}", predictions);
}
```

这种顺手——模型共享 `Fit` / `Predict` trait，指标永远按 `(y_true, y_pred)` 这个顺序取参，一句 `set_global_seed` 就让整个 crate 变得确定——正是本书后面要逐个模块拆开讲的。

## 面向谁

两类读者从相反的方向走来，在这里都能找到熟悉的感觉。第一类是想做机器学习、又不愿离开自家生态的 **Rust 开发者**：不用 `pip`，不用链接 BLAS，没有需要审计的 unsafe FFI，一句 `cargo add` 就够，而且这个 crate 完全遵守 Rust 在所有权、`Send`/`Sync` 和错误处理上的规矩。第二类是**从 Python 转过来的机器学习从业者**，用惯了 scikit-learn 和 Keras，想要同一套心智模型——`fit`/`predict`，Keras 风格、可以 `.add(...)` 层再 `.compile(...)` 的 `Sequential`，以及在 sklearn 里是什么意思、在这里就是什么意思的混淆矩阵和轮廓系数——只不过这一切都以编译型、静态类型、默认并行的 Rust 表达出来。凡是 RustyML 有意与这些工具分道扬镳的地方，本指南都会点明，并说清为什么。

你不需要有用 Rust 写数值代码的经验，但应该能顺畅地读 Rust、会跑 `cargo`。数据自始至终都在 [`ndarray`](https://docs.rs/ndarray) 数组里流动，所以在你随处撞见它之前，[使用 ndarray 准备数据](./Chapter-01/1.3._使用ndarray准备数据.md)会先给这个库一段简短而聚焦的介绍。

## 本书如何组织

整个 crate 拆成五个由 feature 控制的模块——`machine_learning`、`neural_network`、`utils`、`metrics`、`math`——外加一个按领域拆分的 `prelude`。章节编排沿着这个结构，并把唯一一章需要从头读到尾的内容放在最前面。

| 章节 | 覆盖内容 | 对应模块 |
|---|---|---|
| [1. 快速上手](./Chapter-01/1.0._快速上手.md) | 安装、feature 配置、ndarray、第一个端到端模型、prelude、错误处理 | 入门通道 |
| [2. 经典机器学习](./Chapter-02/2.0._经典机器学习.md) | 回归、分类、聚类、降维、异常检测 | `machine_learning` |
| [3. 神经网络](./Chapter-03/3.0._神经网络.md) | `Sequential` 模型，全连接/卷积/循环层，损失函数，优化器，保存权重 | `neural_network` |
| [4. 数据预处理](./Chapter-04/4.0._数据预处理.md) | 训练集/测试集划分，标准化与归一化，标签编码 | `utils` |
| [5. 模型评估](./Chapter-05/5.0._模型评估.md) | 回归、分类、聚类指标 | `metrics` |
| [6. 数学工具](./Chapter-06/6.0._数学工具.md) | 距离度量、矩阵乘法、确定性的并行归约 | `math` |
| [7. 进阶主题](./Chapter-07/7.0._进阶主题.md) | 可复现性与随机种子，模型持久化内部机制，性能调优，最小化构建 | 横向贯通 |

第 2、3 章是两大算法家族，撑起了 crate 的大部分表面积。第 4 到 6 章是配角——喂给模型之前跑的预处理、模型跑完之后算的指标，以及两者共同依赖的数值原语。第 7 章才配得上*进阶*二字：`random_state` 如何相对全局种子解析、一份保存的模型经 postcard 序列化后的字节里究竟装了什么、运行时可调的并行开关怎么工作，以及如何编译出只拉入 `metrics` 或只拉入 `math` 的构建。

## 怎么读这本书

[快速上手](./Chapter-01/1.0._快速上手.md)按顺序、从头到尾读一遍。它是唯一一章假设你读过前面内容的：它装好 crate、搭起 ndarray、搭出一个完整模型，好让后面每一章都能踩在这块共同的地基上，而不必重新推一遍。第 1 章之后的内容都是参考手册式的，也刻意做成了与顺序无关——手头是什么问题就直接翻到[支持向量机](./Chapter-02/2.5._支持向量机.md)、[优化器](./Chapter-03/3.4._优化器.md)或[聚类指标](./Chapter-05/5.3._聚类指标.md)，遇到某一页依赖别处讲过的概念，就顺着正文里的交叉链接跳过去。如果你已经能编译 RustyML、能训练模型，那第 1 章的任务就算完成了；剩下的部分当成一本手册，需要哪一页就翻哪一页。

## 版本、反馈与约定

本版对应当前的 crate 版本 **0.13**。RustyML 尚在 1.0 之前，且处于活跃开发中：API 正在趋于稳定，但次要版本更新中仍可能出现破坏性更改，所以一旦指南里的某个签名与你编译器看到的对不上，请以[对应你确切版本的 docs.rs](https://docs.rs/rustyml) 为准，并告诉我们一声。bug 反馈、功能需求，以及对本指南的勘误，都归到同一个地方——[GitHub 仓库](https://github.com/SomeB1oody/RustyML)，欢迎提 issue 和 pull request。

往下走之前，有两条约定值得先记牢。其一，书中的完整示例都是自带 `main`、内嵌极小数据集、只跑几轮迭代的独立程序，你可以把任意一个粘进一个开了 `full` feature 的项目里原样运行；代码片段和函数签名则会明确标注出来。其二，在 `metrics` 和 `math` 这两个叶子模块之外，所有可能失败的调用都返回 `RustymlResult<T>`——它是 `Result<T, rustyml::error::Error>` 的别名，背后是一个结构化、可 match 的错误枚举——示例里用 `.unwrap()` 只是为了保持简短。[错误处理](./Chapter-01/1.6._错误处理.md)会告诉你在真实代码里该怎么写。
