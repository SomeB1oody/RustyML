# 6. 数学工具

`math` 模块是 RustyML 其余部分赖以立足的数值地基：成对距离内核、`gemm` 支撑的矩阵乘积，还有每个估计器、神经网络层和指标在底层都会调用的确定性并行归约。大多数时候你用着这些原语却叫不出它们的名字——KNN 用的是距离内核，`Dense` 层用的是 GEMM，方差计算用的是分块归约——但可以直接调用的那部分都已导出，当你要实现高层 API 没有覆盖的功能时就能直接拿来用，而可调的那部分则暴露出旋钮，供你按自己的硬件来调。模块在 `math` feature 下编译，`machine_learning`、`neural_network`、`utils`、`metrics` 中任意一个都会传递性地开启它，`full` 也包含它，所以只要你用了 RustyML，这些原语就已经编译好了。参见[安装与Feature配置](../Chapter-01/1.2._安装与Feature配置.md)。

有一条主线贯穿这三节：这些原语并行，却可复现。每个原语都通过把工作量估计与一个校准过的阈值相比较来决定走串行还是走 rayon——归约无论走哪条路都逐位一致，而矩阵乘积在多次运行间可复现（策略翻转可能挪动最后几位，见 6.2.4）。正是这个性质，让[性能调优与并行](../Chapter-07/7.3._性能调优与并行.md)里的旋钮可以放心地拧，也支撑起[可复现性与随机种子](../Chapter-07/7.1._可复现性与随机种子.md)中的那些保证。往下读之前，你应该已经熟悉 ndarray 的 `Array1`/`Array2` 和视图；[使用ndarray准备数据](../Chapter-01/1.3._使用ndarray准备数据.md)讲了你需要的部分。这三节请按顺序读——6.1 和 6.3 给你的是今天就能调用的函数，而 6.2 更多是在为一个你间接调用的后端提供背景。

## 6.1. 距离度量

[距离度量](./6.1._距离度量.md)一节介绍三个不分配内存、逐行计算的内核——`squared_euclidean_distance_row`、`manhattan_distance_row` 和 `minkowski_distance_row`——以及架在它们之上的 `DistanceCalculationMetric` 枚举。这个枚举是 KNN、DBSCAN 和轮廓系数共用的唯一调度器，它把度量方式的选择变成一个运行时的值，而不是写死的 `match`。内核是快路径（欧几里得那个特意跳过了开方），枚举则更顺手。从这里读起——它是本章最能直接上手的部分。

```rust
use ndarray::array;
use rustyml::math::{DistanceCalculationMetric, squared_euclidean_distance_row};

fn main() {
    let a = array![0.0_f64, 0.0];
    let b = array![3.0_f64, 4.0];

    // 原始内核返回的是*平方*距离——不开方。
    println!("squared: {}", squared_euclidean_distance_row(&a, &b)); // 25.0

    // 调度器会开方，并让度量方式在运行时变化。
    let metric = DistanceCalculationMetric::Euclidean;
    println!("euclidean: {}", metric.distance(a.view(), b.view())); // 5.0
}
```

## 6.2. 矩阵乘法

[矩阵乘法](./6.2._矩阵乘法.md)一节讲解库里每一次稠密乘积背后的 `gemm` crate 后端：它如何分派到当前可用的最宽 SIMD，何时在输出列上并行、何时把行拆到 rayon 上，以及为什么矩阵-向量乘积会自成一个成本类别。你很少会直接叫出这一层的名字——它垫在线性模型以及 Dense 层和卷积层底下——所以这一节与其说是在讲一套要调用的 API，不如说是在讲清它的策略，以及更有用的一点：`rustyml::tuning::matmul` 里那组旋钮，能针对你的核数和缓存大小重新校准串行与并行的切换点。当你在意某个模型的吞吐量时，就来读它。

## 6.3. 并行归约

[并行归约](./6.3._并行归约.md)一节介绍 `det_reduce` 和 `det_reduce_range`——两个分块折叠函数，让求和、点积或分桶累加器无论跑在一个线程还是所有线程上都得到相同的位。裸写一个 `par_iter().sum()`，会按 rayon 碰巧如何窃取工作来重排浮点加法的次序；这两个辅助函数则把输入切成固定 `DET_REDUCE_BLOCK` 大小的块，于是分组方式——连带舍入方式——永远不依赖调度。只要你在自己写并行数值循环、又想要一个不随运行次数或线程数漂移的结果，就用它们。
