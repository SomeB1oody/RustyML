# 1.5. Prelude与模块导入

## 1.5.1. 把名字引入作用域的 3 种方式

### 从prelude导入全部内容

```rust
use rustyml::prelude::*;
```

这会把所有的内容导入到当前作用域中，适合于快速上手写代码，不需要去找内容的具体位置。

### 从prelude选择特定模块的内容引入

prelude拆成 4 个子模块，可以按需导入：

```rust
use rustyml::prelude::machine_learning::*; // 经典机器学习估计器、trait和共享枚举
use rustyml::prelude::neural_network::*;   // SequentialBuilder、Sequential、History、Tensor、Shape、层、损失函数、优化器
use rustyml::prelude::metrics::*;          // 评估指标函数和类型
use rustyml::prelude::utils::*;            // standardize、normalize、缩放器、编码器、划分
```

当你写的文件明显只属于一个领域时，就用这种写法。

### 通过精确路径来导入

```rust,ignore
use rustyml::machine_learning::LinearRegression;
use rustyml::traits::{Fit, Predict};
use rustyml::metrics::r2_score;
```

长期维护的库代码应该优先用这种。

## 1.5.2. prelude重新导出了什么

`prelude`是一份手工挑选的清单，它只重导出常用的内容，下面的表格展示了`prelude`下不同模块重导出的具体内容。

### 机器学习

| 分组        | 条目                                                            |
|-------------|-----------------------------------------------------------------|
| 估计器trait | `Fit`, `Predict`, `Transform`, `FitTransform`                   |
| 共享枚举    | `DistanceCalculationMetric`, `RegularizationType`, `KernelType` |
| 回归        | `LinearRegression`, `LeastSquaresSolver`                        |
| 线性分类    | `LogisticRegression`, `generate_polynomial_features`            |
| 近邻        | `KNN`, `WeightingStrategy`                                      |
| 决策树      | `DecisionTree`, `DecisionTreeParams`, `Algorithm`               |
| SVM         | `SVC`, `LinearSVC`                                              |
| 判别分析    | `LDA`, `DiscriminantSolver`, `Shrinkage`                        |
| 聚类        | `KMeans`, `DBSCAN`, `MeanShift`, `estimate_bandwidth`           |
| 降维        | `PCA`, `KernelPCA`, `EigenSolver`, `SVDSolver`                  |
| 流形        | `TSNE`, `TSNEMethod`, `Init`                                    |
| 异常检测    | `IsolationForest`, `Contamination`                              |

### 神经网络

| 分组     | 条目                                                                                                                                                                                            |
|----------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Tensor   | `Tensor`（`ArrayD<f32>` 的别名）                                                                                                                                                                |
| 形状     | `Shape`（`SequentialBuilder::build` 接收的类型）                                                                                 |
| 模型     | `SequentialBuilder`（收集各层）、`Sequential`（`build` 交回的类型）                                                                                                                                                                                    |
| 训练历史 | `History`（每个 epoch 1 条损失，`fit` 的返回值）                                                                                                                                                |
| 上下文   | `Ctx`（层的 `forward` 与 `backward` 共享的单次前向反向缓存、梯度存储和训练标志）                                                                                                                |
| 图模型   | `GraphBuilder`（为非链式拓扑收集节点和层）、`Graph`（`build` 交回的类型）、`NodeId`（图中 1 个节点的句柄）                                                                                     |
| 核心层   | `Dense`, `Embedding`, `Flatten`, `Identity`, `Reshape`, `Reverse`, `Permute`, `RepeatVector`, `Rescaling`, `Activation`                                                                                    |
| 合并层   | `Add`, `Average`, `Concatenate`, `Maximum`, `Minimum`, `Multiply`, `Subtract`                                                                                                                   |
| 激活层   | `Linear`, `ReLU`, `LeakyReLU`, `ELU`, `SELU`, `Sigmoid`, `HardSigmoid`, `Tanh`, `Softplus`, `Softsign`, `Exponential`, `Softmax`, `PReLU`                                                       |
| 卷积     | `Conv1D`, `Conv2D`, `Conv3D`, `Conv1DTranspose`, `Conv2DTranspose`, `Conv3DTranspose`, `DepthwiseConv1D`, `DepthwiseConv2D`, `SeparableConv1D`, `SeparableConv2D`, `PaddingType`, `ConvPadding` |
| 边界     | `ZeroPadding1D/2D/3D`, `Cropping1D/2D/3D`, `Border1D/2D/3D`                                                                                                                                     |
| 池化     | `MaxPooling1D/2D/3D`, `AveragePooling1D/2D/3D`, `GlobalMaxPooling1D/2D/3D`, `GlobalAveragePooling1D/2D/3D`                                                                                      |
| 上采样   | `UpSampling1D/2D/3D`, `Interpolation`, `Factor2D`, `Factor3D`                                                                                                                                   |
| 循环     | `SimpleRNN`, `LSTM`, `GRU`                                                                                                                                                                      |
| 正则化   | `Dropout`, `SpatialDropout1D/2D/3D`, `GaussianDropout`, `GaussianNoise`                                                                                                                         |
| 归一化   | `BatchNormalization`, `LayerNormalization`, `LayerNormalizationAxis`, `GroupNormalization`, `InstanceNormalization`, `UnitNormalization`, `UnitNormalizationAxis`                               |
| 损失函数 | `MeanSquaredError`, `MeanAbsoluteError`, `BinaryCrossEntropy`, `CategoricalCrossEntropy`, `SparseCategoricalCrossEntropy`                                                                       |
| 优化器   | `SGD`, `Adam`, `AdamW`, `RMSprop`, `AdaGrad`                                                                                                                                                    |

`Average` 在这个 crate 里对应 2 个不同的东西。这张表把它列为对输入取平均的合并层，下面的评估指标表把它列为分类分数的平均模式。`use rustyml::prelude::*` 会把两类通配都导入，所以 prelude 的根部用一处显式重导出打破了冲突：裸写的 `Average` 永远是平均模式。要拿到合并层，就走它的全路径 `rustyml::neural_network::layers::Average`。

注意`RMSprop`的大小写（小写的 `p`）。激活函数有 2 种写法：一种是调用上表里的独立层。另一种是在支持输入`Activation`枚举的层里选择一个变体（`Activation::ReLU`、`Activation::Softmax { axis }`、`Activation::LeakyReLU { negative_slope }` 等）或者用一个独立激活层作为输入（它们`impl Layer`并可`Into<Activation>`）。

这张表没有缺口。一个完整模型，从第一次 `add` 到 `predict`，只需要这一行 glob，别的都不用。

`PReLU` 是例外：它持有可训练的斜率，所以它只能是层。完整清单和每个激活函数的公式见 [3.2. 全连接层与激活函数](../Chapter-03/3.2._全连接层与激活函数.md)。

举个例子：`Dense::new`的 1 个参数是`activation: impl Into<Activation>`，你既可以传进去一个`Activation`枚举的变体，也可以传进去一个独立激活层：`Dense::new(8, Activation::ReLU)` 与 `Dense::new(8, ReLU::new())` 等价。

| 分组 | 条目                                                                                                                                                                                                                                  |
|------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 类型 | `ConfusionMatrix`, `MulticlassConfusionMatrix`, `Average`                                                                                                                                                                             |
| 回归 | `mean_squared_error`, `root_mean_squared_error`, `mean_absolute_error`, `median_absolute_error`, `mean_absolute_percentage_error`, `r2_score`, `explained_variance_score`                                                             |
| 分类 | `accuracy`, `roc_auc`, `roc_curve`, `precision_recall_curve`, `average_precision`, `log_loss`, `cohen_kappa`, `top_k_accuracy`                                                                                                        |

和其余模块的错误传播设计不同，指标函数在遇到错误时会直接panic，这是为了保持轻量所设置的，详见[5. 模型评估](../Chapter-05/5.0._模型评估.md)。参数顺序是 `(y_true, y_pred)`，与scikit-learn一致。

## 1.5.3. Feature 开关决定 prelude 的内容

`rustyml::prelude`模块总会被编译，但每个子模块必须得在对应模块的feature开启之后才会出现。所以 `use rustyml::prelude::*` 不等于RustyML的所有内容，它等于的是你开启的feature的所有功能，每个feature的内容详见[1.2 安装与 Feature 配置](./1.2._安装与Feature配置.md)。

| 启用的 feature            | `rustyml::prelude::*` 包含什么                                        |
|---------------------------|-----------------------------------------------------------------------|
| `machine_learning`        | 经典估计器、trait和共享枚举                                           |
| `neural_network`          | `SequentialBuilder`、`Sequential`、`History`、`Tensor`、`Shape`、层、损失函数、优化器 |
| `metrics`                 | 指标函数和混淆矩阵类型                                                |
| `utils`                   | `standardize`、`normalize`、整族缩放器、编码器、划分函数、估计器trait |
| `default`（5 个模块全开） | 所有模块                                                              |
| `full`                    | 所有模块                                                              |
