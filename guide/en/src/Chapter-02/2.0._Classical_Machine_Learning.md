# 2. Classical Machine Learning

Classical machine learning is everything in RustyML that is not a neural network: linear models, trees, kernel methods, clustering, and dimensionality reduction. These algorithms train fast, need little data, and produce models you can inspect and reason about. Reach for them first, and move to [Chapter 3](../Chapter-03/3.0._Neural_Networks.md) only when a problem genuinely needs a deep network. Every estimator in this chapter lives under `rustyml::machine_learning` and shares one small contract: construct it with a validating `new` that returns `Result`, train it with `fit`, and run inference with `predict`. The dimensionality-reduction transformers add `transform` and `fit_transform` on top. Learn that rhythm once and it carries across all thirteen models.

Before starting here, work through [Chapter 1](../Chapter-01/1.0._Getting_Started.md) — especially [Working with ndarray](../Chapter-01/1.3._Working_with_ndarray.md), since every model consumes an `Array2<f64>` feature matrix, and [Error Handling](../Chapter-01/1.6._Error_Handling.md), since constructors and `fit`/`predict` all hand back the crate's `Result`. Encoding and scaling your features is [Chapter 4](../Chapter-04/4.0._Data_Preprocessing.md); the accuracy, silhouette, and R² scores you will judge these models by are [Chapter 5](../Chapter-05/5.0._Model_Evaluation.md).

The shared shape of every model, which the rest of the chapter simply varies:

```rust
use rustyml::machine_learning::LinearRegression;
use ndarray::array;

fn main() {
    // construct -> fit -> predict, the rhythm every estimator repeats
    let mut model = LinearRegression::new(true);
    let x = array![[1.0, 2.0], [2.0, 3.0], [3.0, 4.0]];
    let y = array![6.0, 9.0, 12.0];
    model.fit(&x, &y).unwrap();

    let preds = model.predict(&array![[4.0, 5.0]]).unwrap();
    println!("prediction: {:?}", preds);
}
```

The sections are self-contained, so you can jump straight to the model you need, but reading in order climbs naturally from the simplest estimators to the most involved.

Supervised learning predicts a target from labeled examples. [Linear Regression](./2.1._Linear_Regression.md) fits a continuous target with optional L1/L2 regularization and a choice of gradient-descent or closed-form solver — the best place to internalize the fit/predict loop. [Logistic Regression](./2.2._Logistic_Regression.md) reuses that gradient machinery for binary classification. [K-Nearest Neighbors](./2.3._K_Nearest_Neighbors.md) skips training entirely and classifies by proximity, with a selectable distance metric and weighting scheme. [Decision Trees](./2.4._Decision_Trees.md) carve the feature space into readable if/else rules and support the ID3, C4.5, and CART algorithms with pruning. [Support Vector Machines](./2.5._Support_Vector_Machines.md) cover both a kernelized `SVC` (SMO solver) for curved boundaries and a fast `LinearSVC` for wide, high-dimensional data. [Linear Discriminant Analysis](./2.6._Linear_Discriminant_Analysis.md) classifies and reduces dimensions at once by modeling each class as a Gaussian with a shared covariance.

Clustering groups unlabeled data. [KMeans](./2.7._KMeans_Clustering.md) partitions points into a fixed number of clusters with k-means++ initialization — fast, and the usual default. [DBSCAN](./2.8._DBSCAN.md) finds arbitrarily shaped clusters by density and labels outliers as noise, without being told the cluster count in advance. [Mean Shift](./2.9._Mean_Shift.md) also discovers the number of clusters on its own by climbing a density surface. Score all three with the [clustering metrics](../Chapter-05/5.3._Clustering_Metrics.md).

Dimensionality reduction compresses features while preserving structure. [Principal Component Analysis](./2.10._Principal_Component_Analysis.md) is the linear workhorse for decorrelation and compression. [Kernel PCA](./2.11._Kernel_PCA.md) extends it to nonlinear structure through RBF, polynomial, and other kernels. [t-SNE](./2.12._t-SNE.md) embeds high-dimensional data into two or three dimensions for visualization only; it learns no reusable projection, so it exposes `fit_transform` alone and has no out-of-sample `transform`.

Anomaly detection is a family of its own: [Isolation Forest](./2.13._Isolation_Forest.md) scores how easily each point is isolated by random splits, flagging outliers without any labels.
